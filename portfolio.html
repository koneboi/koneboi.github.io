Projects & Code

Reproducible pipelines and models for pathogen genomics, AMR surveillance and infectious-disease epidemiology — each applied to real public datasets.

Bioinformatics & Genomics

RNA-seq

RNA-seq Differential Expression Pipeline

RNA-seq differential expression analysis pipeline — normalisation, DE (Welch's t-test + BH), volcano, PCA, heatmap, MA plot, GSEA.

  • Real data GEO GSE52778 (dexamethasone vs control, human airway smooth muscle)
  • 197 DE genes — 135 up / 62 down (FTL, COL1A2, PER1…)

Single-Cell

Single-Cell RNA-seq Analysis (scanpy)

Single-cell RNA-seq analysis pipeline (scanpy) — QC, normalization, HVG, PCA, Leiden clustering, marker detection, annotation, trajectory.

  • Real data 10x Genomics PBMC3k (2,638 cells × 13,656 genes)
  • 6 cell types recovered by markers (CD79A, NKG7, PPBP, LYZ…)
Repository Results
Phylogenetics

Phylogenetics Analysis Pipeline

Phylogenetic analysis pipeline — MSA (MAFFT), distance matrices & NJ trees, molecular evolution (dN/dS), recombination-aware workflows, visualisation.

  • Real data 29 NCBI 16S rRNA sequences
  • Monophyletic groups: Actinobacteria & α/γ-Proteobacteria purity = 1.0
Repository Results
Phylodynamics

Phylodynamic Analysis of Pathogens

Phylodynamic analysis of pathogens — molecular clock dating (root-to-tip), coalescent skyline population growth, lineage growth, AMR clade expansion timing.

  • Real data 22 SARS-CoV-2 complete genomes (2020–2026)
  • Clock rate 1.25×10⁻³ subs/site/yr (published range)
Repository Results
GWAS

Bacterial GWAS Pipeline

Bacterial GWAS pipeline — SNP matrix construction, population structure (PCA/FST), logistic-regression association testing, Manhattan/QQ plots, candidate genes.

  • Real data S. pneumoniae (Maela, Thailand) — 100 isolates × 5,000 SNPs
  • 706 FDR / 5 Bonferroni hits, λGC=2.9
